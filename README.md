# 2026년 시급 계산기 (Pay Calculator)

2026년 법정 최저시급(10,320원) 기준 기본급, 주휴수당, 가산수당(연장·야간·휴일), 4대보험 및 3.3% 원천징수 세금, 실수령액과 총인건비를 정확하게 산출하는 반응형 웹 계산기입니다.

## ✨ 주요 기능

- **2026년 최신 요율 완벽 반영**:
  - 2026년 최저시급 10,320원 기본 적용 (최저임금 미달 시 경고)
  - 국민연금: 9.5% (근로자 4.75% / 사업주 4.75%)
  - 건강보험: 7.19% (근로자 3.595% / 사업주 3.595%)
  - 장기요양: 건강보험료 × 13.14% (각 50%)
  - 고용보험: 근로자 0.9% / 사업주 1.15% (150인 미만 우선지원대상기업)
  - 산재보험: 사업주 1.47% (업종 평균)
  - 사업소득세: 3.3% 원천징수
- **근로기준법 가산수당 정밀 산출**:
  - 5인 이상 / 5인 미만 사업장 구분 처리
  - 연장근로 1.5배 (5인 이상) / 1.0배 (5인 미만)
  - 야간근로(22:00~06:00) 0.5배 가산 중복 적용
  - 휴일근로 8시간 이내 1.5배, 8시간 초과 2.0배
- **초단시간 근로자 4대보험 조건 자동 판정**:
  - 주 15시간 미만 주휴수당 0원
  - 월 60시간 미만 국민연금·건강보험 자동 제외
  - 주 15시간 미만 고용보험 제외 (3개월 이상 계속근로 시 가입 옵션 지원)
  - 산재보험은 시간 무관 사업주 100% 부담
- **순수 계산 엔진 분리 (`assets/js/wage-core.js`)**:
  - UI와 비즈니스 로직이 완전히 분리되어 연도별 요율(`RATES`)만 수정하면 매년 최신 법령 대응 가능
  - Vanilla JS 기반으로 외부 라이브러리 없이 가볍고 빠름
